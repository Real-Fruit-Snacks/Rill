Features

Raw speed. Zero bloat.

Pure Assembly

Built at the lowest practical level, every applet in Rill is hand-written in NASM assembly and bypasses the dynamic linker.

Zero Dependencies

Ships with zero libc dependencies and avoids global allocators. Every byte the kernel interacts with originates from readable .asm files.

41 Included Applets

Features all the POSIX classics: ls, cp, mv, rm, cat, wc, grep, find, and more, bundled into a single ~108 KB executable.

Workflow

Drop-in replacement for coreutils.

1

Subcommand Dispatch

Invoke any included utility by passing it as a subcommand: ./rill ls -la

2

Symlink Dispatch

Create a symlink to Rill with the name of the utility you want to run. Rill automatically detects its invocation name and executes the correct applet.

3

Integration Tested

Backed by a 329-case bats integration suite that enforces byte-for-byte parity against standard /usr/bin/<applet> equivalents.

Get Started

Install in under a minute.

Installation

  1. Download the binary: curl -LO https://github.com/Real-Fruit-Snacks/Rill/releases/latest/download/rill-linux-x64
  2. Make it executable: chmod +x rill-linux-x64
  3. Rename it: mv rill-linux-x64 rill
  4. Run it: ./rill date
